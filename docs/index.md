# CODSOFT Internship Projects — Documentation

> A comprehensive portfolio repository containing web development tasks developed during the CodSoft internship program.

## Project Purpose
The CODSOFT repository organizes multiple web development projects across progressive skill levels. It encompasses foundational frontend challenges, interactive JavaScript utilities, and a full React single-page quiz application.

## Key Features
- **Level 1 Tasks**:
  - *Task 1*: Personal developer portfolio showcase.
  - *Task 2*: Responsive product landing page.
  - *Task 3*: Interactive JavaScript calculator.
- **Level 2 Tasks**:
  - *Task 1*: Tribute page with responsive typography.
  - *Task 2*: Utility web applications (Job board / Text word counter).
  - *Task 3*: Online Quiz App built with React (Create React App) featuring score tracking and dynamic questionnaires.

## Tech Stack
| Layer | Technology | Purpose |
|---|---|---|
| Core Web | HTML5, CSS3, JavaScript (ES6) | Foundations for Level 1 and Level 2 static tasks |
| Front-end Framework | React (v18), Create React App | Powers Level 2 Task 3 Online Quiz Application |
| Layout & Design | Flexbox, CSS Grid, Responsive Media Queries | Responsive UI across all tasks |
